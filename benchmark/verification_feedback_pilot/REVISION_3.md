# Contract enforcement regression, separate from the matched pilot

The R2 snapshot and all its attempts are retained unchanged. R3 is an APEXA-only
regression study motivated by observed frame-selection, model-assessment and
repair-provenance errors. It changes the system, the tool affordances and the
prompt. It is neither a repeat of the R2 feedback ablation nor an unbiased estimate
of harness ranking. These reused acquisitions informed the changes.

The production change pins a supplied calibration contract per query. Native
calibration dispatch binds the image, phase template, pixel pitch, energy, exact
frame list/reduction, transform, engine/pipeline and distortion model. It records
the model's proposed arguments and every correction. Native return values produce
client-owned execution receipts; conditional finalization verifies the artifact
against that receipt or the original pinned handoff. It retains the proposed
decision, adds actual repair provenance and records the physical scope limits.
The full model has no zero-distortion requirement. Historical handoff evidence
does not become a live execution receipt. Shell-written outputs remain subject
to external audit; the system is not a security boundary against same-user code.

Eight attempts: the same four qualified handoffs, two fresh sessions each, all
with automatic initial feedback. Order: scale_valid, restriction_fault,
scale_fault, restriction_valid, one pair per wave. GPT-OSS-120B, medium reasoning,
65,536 context, 8,192 output tokens, 120 requests, 3,600 seconds and four physical
CPU cores per attempt; two slots. No fixed Pi result is relabeled as an R3 trial.
No original numerical fixture is regenerated.

Qualification must pass production-path regression tests, all four supplied
handoff checks, retrieval/source identity checks and a fresh native model session
that actually calls the contract loader. Exact executable/configuration hashes
must match at qualification, freeze and admission. Preserve failures; no automatic
replacement attempts. Wait for R2's scientific-run lock before R3 admission.

Report decisions, artifact integrity, correct frames/phase/model, repair receipts,
remaining unsupported claims, requests/time, and system guard corrections
separately. A guard-corrected result is a system benefit, not proof of improved
model reasoning. Existing external scoring and fresh trace audits remain required.
Do not add these results to the paper until attempts and audits are complete.
