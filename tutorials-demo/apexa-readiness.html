02 / Scientific canvas

Structures, detector frames, and analysis in one workspace.

Crystal structures

MP/COD CIF outputs open as interactive 3D cells with symmetry-expanded sites and occupancy.

Detector sequences

Frame navigation, playback, dark subtraction, masks, raw/corrected view, contrast, and radial profiles.

Ring guides

CIF-derived powder ring positions using explicit energy, detector distance, pixel size, and center.

Ring guides currently assume an untilted detector without distortion; they do not predict intensity or certify calibration.

03 / Keep the evidence together

Reports alongside the view they describe.

Viewer inspection reports follow accepted frames and record source identity, correction files, display settings, statistics, and ring-model scope. Historical reconstruction reports retain their original context.

04 / Deploy where the data lives

Three operating modes.

CONNECTED COORDINATOR

SSH to the beamline

Model access on an approved host; remote scientific work and previews through SSH.

ANL INTERNAL

Beamline + internal model

Local analysis with an ANL-internal endpoint and staged dependencies and reference data.

FULLY DISCONNECTED

Local model + MIDAS

Preinstalled model weights, scientific engines, cached knowledge, and local CIFs.

No internet means no live MP/COD retrieval. A fully disconnected host also has no incoming SSH route.

05 / Demonstrate, then commission

A demo that makes the evidence visible.

Open a saved CIF → inspect the structure → load a small detector sequence → apply a known dark and mask → inspect the radial profile → overlay ideal rings → open the report alongside the image.

Then qualify FF/NF reconstruction against approved reference results and measure latency, restart behavior, and resource use on each deployment host.
